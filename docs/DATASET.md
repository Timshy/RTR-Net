# Dataset preparation

This repository does not redistribute Massachusetts, DeepGlobe, SpaceNet, CHN6-CUG, RiverScope, WHU-RuRp, or GRSet.

Please download each dataset from its official source and convert it to:

```text
data/<dataset>/
├── images/
├── masks/
└── responses/
```

- `images/`: RGB remote-sensing images.
- `masks/`: binary foreground masks.
- `responses/`: continuous category semantic response maps generated by a frozen open-vocabulary model.

Images, masks, and response maps should share the same filename stem.
